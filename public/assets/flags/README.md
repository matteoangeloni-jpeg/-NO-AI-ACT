# Language-selector flag assets

PNG assets downloaded on 18 October 2026 from Flagpedia's FlagCDN service:
https://flagpedia.net/download/api

Sources: https://flagcdn.com/w80/{it,gb,fr,de,es,pt}.png
The provider describes these as freely downloadable flag images based on
Wikimedia Commons vectors. No project authorship of the flag designs is claimed.

Assets are served locally, without contacting a third-party CDN at runtime.
Flags are decorative cues alongside written language names, not standalone
language identifiers. GB accompanies English; PT accompanies European Portuguese.
