Wie zu zitieren NO AI ACT

Wenn Sie NO AI ACT in einer Abschlussarbeit, einer Arbeit, einer Klassenzimmerstudie oder einer abgeleiteten Arbeit verwenden, erhalten Sie auf dieser Seite die richtigen Zitationsformate. genaue Fassung Sie verwendet haben: Das Spiel entwickelt sich, und der Fallinhalt kann zwischen den Versionen wechseln.

01APA-Zitat

APA (7. Ausgabe) Format für Software:

Angeloni, M. (2026). NO AI ACT — Simulatore di una società non regolata (Version 5.4.0) [Software]. https://www.no-ai-act.eu/

Ersetzen Sie "5.4.0" durch die Version, die Sie tatsächlich verwendet haben: Sie wird in der Website-Fußzeile, auf dem Titelbildschirm des Spiels und im Repository angezeigt package.json.

02BibTeX

@software{angeloni_no_ai_act_2026,
  author  = {Angeloni, Matteo},
  title   = {NO AI ACT --- Simulatore di una societ{\`a} non regolata},
  year    = {2026},
  version = {5.4.0},
  url     = {https://www.no-ai-act.eu/},
  note    = {Source code: https://github.com/matteoangeloni-jpeg/-NO-AI-ACT.
             GPL-3.0-licensed code; educational content CC BY-SA 4.0.}
}

03Warum die genaue Version wichtig ist

  • Reproduzierbarkeit: Fälle, Texte und Bewertungsregeln werden pro Version festgelegt. Jeder, der eine Studie repliziert, muss in der Lage sein, genau das abzurufen, was die Teilnehmer gesehen haben.
  • Wo man es finden kann: die Fußzeile des Standorts, package.jsonund die Release-Tags auf GitHub Releases.
  • Historisches Archiv: Jedes getaggte GitHub-Release bewahrt den Code und den Inhalt dieser Version.

04ROI

Ein DOI (Digital Object Identifier) ist noch nicht verfügbar. Das Projekt soll mit dem Release 2.0 auf Zenodo archiviert werden: Sobald der DOI live ist, wird er hier im CITATION.cff Datei und im Repository README. Bis dahin die kanonische URL und die Version zitieren.

05Die Datei CITATION.cff

Das Repository Ships a CITATION.cff Datei im Citation File Format: GitHub liest sie automatisch und zeigt die Schaltfläche "Cite this repository" an, und Referenzmanager können sie direkt importieren.
