Le jeu ajoute un registre facultatif pour chaque session d’un adulte consentant : actions, pièces, choix, comparaisons, révisions, aides et retours. Le partage des textes enregistrés du parcours guidé nécessite un accord supplémentaire.

File d’attente par onglet, renvois idempotents, confirmation explicite des événements reçus, retrait et effacement, export personnel et reçu privé. Conservation de 90 jours ; enregistrement pendant 24 heures au maximum dans le même onglet.

Le tableau de bord privé montre les sessions et leurs événements ordonnés, avec filtres combinés et exports JSON/CSV. Les agrégats historiques restent séparés ; les alias qui masquaient les dossiers terminés sont corrigés.

Les six langues, 14 dossiers, sauvegardes v1/v2 et textes accessibles sont conservés. Consentement et information de confidentialité sont traduits dans les six langues.

Les anciens parcours individuels ne peuvent pas être reconstruits à partir des agrégats. Aucune garantie d’envoi complet, note automatique d’esprit critique, identification entre visites ou activation de Study 02. Aucun smoke test, conformément à la demande ; résultats effectifs dans le journal de publication.
