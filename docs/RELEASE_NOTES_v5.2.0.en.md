# NO AI ACT v5.2.0 — consented detailed session records

[Italiano](RELEASE_NOTES_v5.2.0.md) · [English](RELEASE_NOTES_v5.2.0.en.md) · [Français](RELEASE_NOTES_v5.2.0.fr.md) · [Deutsch](RELEASE_NOTES_v5.2.0.de.md) · [Español](RELEASE_NOTES_v5.2.0.es.md) · [Português](RELEASE_NOTES_v5.2.0.pt.md)

2026-11-22

The game adds an optional record for each consenting adult session: actions, exhibits, choices, comparisons, revisions, help and feedback. Sharing saved guided-path writing requires additional consent.

A per-tab queue, idempotent retries, explicit event acknowledgements, withdrawal and erasure, personal export and a private receipt. Retention is 90 days; recording lasts up to 24 hours in the same tab.

The private dashboard shows individual sessions and ordered event timelines, with combined filters and JSON/CSV exports. Legacy aggregates remain separate; event aliases that hid case completions are corrected.

All six languages, 14 cases, v1/v2 saves and accessible text remain supported. Consent controls and the privacy notice are translated into all six languages.

Old individual journeys cannot be reconstructed from aggregates. No complete-delivery guarantee, automated critical-thinking score, cross-visit identification or Study 02 activation. No smoke tests, as requested; actual checks are recorded in the release log.
