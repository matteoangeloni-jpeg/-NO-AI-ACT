Geplande commando's: npm run typecheck, npm test, npm run build, npm run audit:seo, npm run check:dist, npm run rook:guided-inquiry, npm run rook:release-cases en npm run rook:final-modes. Technische tests vormen geen educatieve validatie of toegankelijkheidscertificering.

Vereist bevel tot voltooiing. Schrijf alle bemiddelings-, componenten-, transfermateriaal- en observatie-instrumenten voordat u met de tests begint. Voer vervolgens de gehele suite, geleid rookdekking van 14-cases × drie talen en zes lay-outprofielen, Study 02 dekking van twee vormen × drie talen × PRE/POST, en catalogus/modus regressies. Voor een correctie tijdens de tests moeten de desbetreffende controles vóór de levering opnieuw worden uitgevoerd. Tests maken gebruik van synthetische gegevens en leveren geen bewijs van menselijk leren.

De bestaande telemetrieMetrics.ts omvat tegenstrijdigEvidenceErkend, afgeleid van het openen van bepaalde expositie categorieën. Zijn naam kan meer betekenen dan het gedrag aantoont. Beschouw het in Study 02 als een technische exposure-proxy; doe geen contradictie-herkenning zonder de uitleg van de deelnemer. Deze verhoging verandert het telemetrieschema niet.

## Menselijk protocol nog steeds te voeren

Rekruteer beginners en ervaren deelnemers met toestemming voor observatie en notities. Een eerste iteratie met 5–8 deelnemers per profiel kan obstakels blootleggen zonder de effectiviteit te schatten. Record CEPAJe context, taal, apparaat, hulp, onderbrekingen en leesproblemen.

Taken: uitleg over het doel van classificatie, vorm een hypothese, vind en verbind twee bronnen, identificeer een alternatief, schrijf voor ondertekening, herlees na feedback en leg revisie of bevestiging uit. De facilitator registreert onafhankelijk succes, succes met hulp, niet-voltooien, ernstige fout en de aangegeven reden. Niet classificeren klik telt als kritisch denken.

Design-revision criteria. Onvermogen om een dialoogvenster te verlaten, toevallige ondertekening, verlies van tekst binnen een sessie of een prompt die de oplossing onthult, vereist correctie voordat het prototype wordt uitgebreid. Om inzicht te krijgen, moet een operationele pilotdrempel worden vastgesteld, zoals ten minste vier van de vijf beginners die de taak in hun eigen woorden uitleggen. Ook disharmonische zaken melden. Dit is een productbeslissing, geen test van de effectiviteit.

Test echte schermlezers, dictee of gemedieerde transcriptie, toetsenbordnavigatie en aanraking met een on-screen toetsenbord. Zorg voor een gelijkwaardige orale respons route voor mensen die te maken hebben met schrijfbarrières. Alle drie talen vereisen een menselijke beoordeling voordat de aanwerving voor Study 02.

Dit is het oorspronkelijke methodologische verificatieplan. Het vertalen van het niet zijn rooktests herhalen: de V5.0.1 lokalisatiecorrectie wordt gecontroleerd met statische taalcontroles, eenheid testen en alleen bouwen, zoals gevraagd door de eigenaar.
