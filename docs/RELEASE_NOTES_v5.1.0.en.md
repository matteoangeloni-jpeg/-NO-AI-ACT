- All 14 cases, evidence, rationales, rules, feedback, guided inquiry, glossary, reports and accessible text are translated. Each new version contains 1,581 strings, including 42 brand, author and internal-key invariants.
- Direct language selection uses two rows. Document language and titles follow the selection; both `?lang=pt` and `?lang=pt-PT` open European Portuguese.
- Twelve teaching resources have translated captions and existing destination pages. DE/ES/PT link to a classroom workshop and a teacher introduction.
- The statistics notice, aggregate-counter opt-out and beta interface cover all six languages. The collector accepts the new languages while retaining earlier clients. No individual data is added.
- Save schema v2, v1 migration and evidence/rationale indices are preserved. All 155 website pages retain their URLs.

Release checks cover unit tests, typechecking, builds, SEO auditing and distribution integrity. Actual results appear in the release record. No smoke tests were run for this release, at the owner's request.

The historical methodology dossier and Study 02 remain in IT/EN/FR, outside the public game build. Technical coverage does not establish linguistic equivalence or educational effectiveness: specialist bilingual review and real assistive-technology testing remain pending. Images retain the original Italian V5.0.0 archive and are not presented as new V5.1.0 screenshots. Earlier tags are unchanged.
