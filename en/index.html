03The open case files.

Thirteen cases, from the clearest to the most ambiguous. Each holds a decisive signal, an account that minimises the problem, and a contextual element that can flip the reading.

  • FILE 01AVAILABLE The city of scores Civic administration PROHIBITED PRACTICE One score decides housing, healthcare and school. The penalty migrates across unrelated contexts.
  • FILE 02AVAILABLE The interview that never happened Employment and hiring HIGH RISK Automated screening of applications, with no explanation and no way to contest it.
  • FILE 03AVAILABLE The synthetic city Public communication TRANSPARENCY A city council floods its channels with generated content, unlabelled and unwatermarked.
  • FILE 04AVAILABLE The observed classroom Education · Emotion recognition PROHIBITED PRACTICE The system infers emotional states from students' faces. No way to contest the result.
  • FILE 05AVAILABLE Invisible triage Healthcare HIGH RISK Excellent averages, errors concentrated on certain groups, and blind trust from supervisors.
  • FILE 06AVAILABLE Faces in the crowd Public space · Biometrics PROHIBITED PRACTICE Live biometric identification, in public squares, for law-enforcement purposes.
  • FILE 07AVAILABLE Civic credit Welfare · Credit BOUNDARY CASE Mirror case: where does creditworthiness assessment end and social scoring begin?
  • FILE 08AVAILABLE The desk that always answers Citizen services TRANSPARENCY An automated assistant creates reliance. The disclosure exists — but is it enough?
  • FILE 09AVAILABLE The opaque tender Public procurement HIGH RISK AI procurement with no technical documentation and no declared governance.
  • FILE 10AVAILABLE The profiled classroom Adaptive EdTech HIGH RISK A learning platform profiles students and steers their educational path.
  • FILE 11AVAILABLE The do-it-all model GPAI · Downstream use GPAI A general-purpose model used downstream in internal decisions nobody classified.
  • FILE 12AVAILABLE The marked district Predictive policing PROHIBITED PRACTICE Predicting the person, not the phenomenon: the line the AI Act draws sharply.
  • FILE 13AVAILABLE The algorithm of suspicion Welfare · Fraud detection HIGH RISK Fraud scoring on an essential benefit, with human oversight in name only.

09Frequently asked questions

What is NO AI ACT?
It is a free investigative serious game about the European AI Act. You investigate artificial intelligence systems, examine the evidence and file a report classifying their risk.
Is NO AI ACT legal advice?
No. It is a simplified educational simulation. It is not legal advice and does not replace the text of the regulation or the opinion of a professional.
Do I need to register or create an account?
No. There is no registration, no account, no backend. The game runs entirely in the browser and progress is stored only locally.
How many cases can I play?
Thirteen cases, from the clearest to the most ambiguous: from prohibited social scoring and predictive policing to high-risk systems in healthcare, schools and welfare, up to generative models used downstream.
Is it suitable for classroom teaching?
Yes. It is designed for upper-secondary schools, universities and professional training. There is a teacher mode with a local debrief and missions of varying length. No student data is collected.
Does NO AI ACT collect personal data?
No. The game collects no personal data and does not send results, answers or inspection reports to any server. Public pages use aggregate, privacy-friendly statistics via Cloudflare Web Analytics; there are no accounts or classroom dashboards.
