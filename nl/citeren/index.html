Citatie · Onderzoek · Hergebruik

Hoe kan ik NO AI ACT citeren?

Als je NO AI ACT gebruikt in een proefschrift, een paper, een klaslokaalstudie of afgeleid werk, dan geeft deze pagina je de juiste citaatformaten. Vermeld altijd de exacte versie je gebruikt: het spel evolueert, en de inhoud van het geval kan veranderen tussen versies.

01APA-aanhaling

APA (7e editie) formaat voor software:

Angeloni, M. (2026). NO AI ACT — Simulatore di una società non regolata (Version 5.4.0) [Software]. https://www.no-ai-act.eu/

Vervang "5.4.0" door de versie die je eigenlijk gebruikt: het wordt weergegeven in de site footer, op het titelscherm van het spel, en in de repository's package.json.

02BibTeX

@software{angeloni_no_ai_act_2026,
  author  = {Angeloni, Matteo},
  title   = {NO AI ACT --- Simulatore di una societ{\`a} non regolata},
  year    = {2026},
  version = {5.4.0},
  url     = {https://www.no-ai-act.eu/},
  note    = {Source code: https://github.com/matteoangeloni-jpeg/-NO-AI-ACT.
             GPL-3.0-licensed code; educational content CC BY-SA 4.0.}
}

03Waarom de exacte versie belangrijk is

  • Reproduceerbaarheid: gevallen, teksten en scoreregels worden gepind per versie. Iedereen die een studie repliceert, moet precies kunnen ophalen wat de deelnemers zagen.
  • Waar vind je het?: de site footer, package.json, en de release tags op GitHub releases.
  • Historisch archief: elke tagged GitHub release behoudt de code en inhoud van die versie.

04DOI

Een DOI (Digital Object Identifier) is nog niet beschikbaar. Het project is gepland om te worden gearchiveerd op Zenodo met de 2.0 release: zodra de DOI is live zal het hier worden gepubliceerd, in de CITATION.cff bestand en in de repository README. Tot dan, citeer de canonieke URL en de versie.

05Het CITATION.cff-bestand

Het archief verscheept een CITATION.cff bestand in het Citation File Format: GitHub leest het automatisch en toont de "Cite this repository" knop, en referentie managers kunnen het direct importeren.

07Context voor het citeren van auteurs

NO AI ACT is een educatieve simulatie Verordening (EU) 2024/1689: de wet wordt bewust vereenvoudigd en is geen juridisch advies. De effectiviteit van het onderwijs is nog niet empirisch gevalideerd: in publicaties wordt het beschreven als een open-source onderwijsinstrument, niet als een interventie met bewezen effectiviteit. Het volledige methodologische kader is: onderzoek en methodologie; mediamateriaal bevindt zich in de persmap.
