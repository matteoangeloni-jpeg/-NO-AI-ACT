Citation · Recherche · Réutilisation

Comment citer NO AI ACT

Si vous utilisez NO AI ACT dans un mémoire, un article, une étude en classe ou un travail dérivé, cette page fournit les formats de citation. Indiquez toujours la version exacte utilisée : le jeu évolue et les cas peuvent changer.

01Citation APA

Format APA (7e édition) pour un logiciel :

Angeloni, M. (2026). NO AI ACT — Simulatore di una società non regolata (Version 3.0.0) [Logiciel]. https://www.no-ai-act.eu/

Remplacez « 3.0.0 » par la version effectivement utilisée, indiquée dans le pied de page, sur l'écran titre du jeu et dans le fichier package.json du dépôt.

02BibTeX

@software{angeloni_no_ai_act_2026,
  author = {Angeloni, Matteo},
  title = {NO AI ACT --- Simulatore di una societ{\`a} non regolata},
  year = {2026},
  version = {3.0.0},
  url = {https://www.no-ai-act.eu/},
  note = {Code source : https://github.com/matteoangeloni-jpeg/-NO-AI-ACT. Code sous GPL-3.0 ; contenus pédagogiques sous CC BY-SA 4.0.}
}

03Pourquoi la version exacte compte

  • Reproductibilité : cas, textes et règles d'évaluation sont associés à une version. Une étude doit pouvoir retrouver exactement ce qu'ont vu ses participants.
  • Où la trouver : pied de page, package.json et versions étiquetées dans GitHub Releases.
  • Archive historique : chaque release GitHub étiquetée conserve le code et les contenus correspondants.

04DOI

Un DOI (Digital Object Identifier) n'est pas encore disponible. L'archivage sur Zenodo était prévu avec la version 2.0 ; quand le DOI sera disponible, il sera publié ici, dans CITATION.cff et dans le README. En attendant, citez l'URL canonique et la version.

05Le fichier CITATION.cff

Le dépôt contient un fichier CITATION.cff au format Citation File Format. GitHub le lit pour proposer « Cite this repository », et les gestionnaires bibliographiques peuvent l'importer.

07Contexte pour les auteurs qui citent le projet

NO AI ACT est une simulation pédagogique du règlement (UE) 2024/1689 : il simplifie volontairement le droit et ne constitue pas un conseil juridique. Son efficacité pédagogique n'a pas encore été validée empiriquement. Décrivez-le comme un outil pédagogique open source, pas comme une intervention à l'efficacité démontrée. Voir recherche et méthodologie et le dossier de presse.

Essayer le jeu Recherche et méthodologie

Simulation pédagogique — pas un conseil juridique

NO AI ACT est un outil pédagogique indépendant et open source. Il simplifie délibérément le règlement (UE) 2024/1689 (AI Act) et ne remplace ni le texte juridique ni l'avis d'un professionnel.
